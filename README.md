# homebrew-tap

Personal Homebrew tap for my macOS apps.

- [Package Inspector](https://github.com/souvickcse/npm-Package-Inspector) — see what's installed in a Node.js project
- [Pass Generator](https://github.com/souvickcse/PassGenerator) — build signed Apple Wallet (.pkpass) files

## Install

```bash
brew install souvickcse/tap/package-inspector
brew install souvickcse/tap/pass-generator
```
